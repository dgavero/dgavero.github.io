This is a personal portfolio website being modernized.

## General Rules

- It is OK to refactor HTML, CSS, and JS
- Preserve existing content and data unless explicitly told to remove it
- Prefer improving structure, readability, and responsiveness
- Do not over-engineer or introduce frameworks unless requested

## Style & UX

- Keep things simple and clean
- Prefer modern, minimal layouts
- Avoid unnecessary animations

## Safety

- Make incremental changes
- Explain major changes before applying them
